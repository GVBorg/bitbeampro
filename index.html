Calibration reference points

Record each moving head's Pan/Tilt at the same stage marks, then recall all heads at a recorded mark. This stores measured positions; geometric targeting between marks is not included. Physical alignment becomes possible after DMX output is connected.

Ableton Link — DJ tempo

Joins the Ableton Link session as a read-only peer and takes the live tempo (fractional) and beat grid from the DJ app — djay Pro, Serato, Traktor, Live — on the same Wi-Fi. BitBeam never sets the session tempo. Tempo priority: Link > skeleton (locked track) > mic.
