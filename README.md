# BitBeam — Web Demo

Static demo of the BitBeam Live page (MAIN / ABOUT / DOWNLOAD).
Runs entirely in the browser: no server, no backend, no build step.

Deploy: put ALL files of this folder into the repository root (or any folder) and enable GitHub Pages.
`index.html` must stay next to the other files. Keep `.nojekyll`.

Presets saved by visitors are stored in their own browser (localStorage).
Reset for a visitor: open DevTools console and run `BitBeamDemoReset()`.
